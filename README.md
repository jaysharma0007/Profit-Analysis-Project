📊 PRDA-01 – Profit Analysis using Multiple Linear Regression
Multiple Linear Regression Analysis of Startup Profit

Python • Pandas • NumPy • Scikit-learn • Matplotlib • Power BI

📌 Project Overview
This project analyzes the factors affecting the Profit of startups using Multiple Linear Regression.

The analysis focuses on three major expenditure variables:

R&D Spend
Administration Spend
Marketing Spend
The main objective is to understand how these spending variables are associated with startup Profit and to build a regression model capable of predicting Profit for given input values.

The project also uses Power BI to visualize relationships, trends, and state-wise performance.

🎯 Objectives
Analyze startup expenditure and Profit data.
Identify the relationship between R&D, Administration, Marketing Spend and Profit.
Perform data preprocessing using Python.
Select relevant features for regression analysis.
Build a Multiple Linear Regression model.
Evaluate the model using R² Score and Mean Squared Error (MSE).
Predict Profit for given expenditure values.
Create visualizations using Power BI.
Generate business insights and recommendations.

🤖 Machine Learning Model
Multiple Linear Regression
Multiple Linear Regression is a supervised machine learning algorithm used to predict a continuous dependent variable using multiple independent variables.

In this project, the model predicts Profit using:

R&D Spend
Administration Spend
Marketing Spend
Regression Equation
Profit = β₀ + β₁(R&D Spend) + β₂(Administration) + β₃(Marketing Spend)
Where:

β₀ = Intercept
β₁ = R&D Spend coefficient
β₂ = Administration coefficient
β₃ = Marketing Spend coefficient
📊 Train-Test Split
The dataset was divided into training and testing datasets using an 80:20 ratio.

test_size = 0.2
random_state = 42
80% → Training Data
20% → Testing Data
The training data was used to learn the relationship between expenditure variables and Profit, while the testing data was used to evaluate model performance.
